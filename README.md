# CareMate AI – Agentic Elderly Care Assistant

## Problem

Many elderly people forget medications, miss appointments, struggle to
understand health readings, and may not receive immediate assistance during
emergencies.

## Solution

CareMate AI is an Agentic AI system that reminds elderly users about
medications and appointments, analyzes health data, provides conversation and
memory exercises, answers healthcare questions using RAG, and alerts caregivers
when dangerous situations are detected.

## Target Users

- Elderly People
- Caregivers
- Family Members

## Features

- Medication reminders
- Appointment reminders
- Blood pressure monitoring
- Blood sugar monitoring
- Health chatbot
- Memory exercises
- Emotional support
- Emergency alert system
- Daily health summary
- Caregiver dashboard
