# Agents

## 1. Coordinator Agent
Receives every user request and decides which agent should handle it.

## 2. Reminder Agent
Manages medication and appointment reminders.

## 3. Health Agent
Analyzes blood pressure and blood sugar readings.

## 4. Conversation Agent
Chats with elderly users and provides memory exercises.

## 5. Alert Agent
Sends emergency notifications to caregivers.

## 6. Summary Agent
Creates daily and weekly reports.
